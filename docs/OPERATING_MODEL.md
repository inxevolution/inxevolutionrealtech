# In X Evolution — Enterprise Operating Model

**Version:** 0.1 · **Status:** Proposed.

## Model

Use a portfolio model with shared governance and enabling services, while each business line remains accountable for products, customers, delivery, costs and risks.

## Shared functions

Strategy and portfolio management; brand standards; finance oversight; legal/privacy/compliance coordination; identity and security policy; procurement; data governance; reporting.

## Business-line responsibilities

Each active line owns its offers, customer workflows, product lifecycle, delivery quality, direct costs, support and line-specific risks.

## Draft RACI

R = Responsible; A = Accountable; C = Consulted; I = Informed.

| Activity | Project owner | Line owner | Product owner | Technical lead | Finance/legal |
|---|---|---|---|---|---|
| Strategy and scope | A | C | C | C | C |
| Offer definition | I | A | R | C | C |
| Requirements and acceptance | I | A | R | C | C |
| Architecture | I | C | C | A/R | C |
| Budget approval | A | R | C | C | R/C |
| Production release | I | A | R | R | C |
| Regulatory review | A | R | C | C | R |
| Risk acceptance | A | R | C | C | C |

Named assignments must be approved. This is a draft role allocation, not an appointment.

## Cadence proposal

- Weekly delivery coordination during active implementation.
- Monthly business-line review of customer outcomes, costs, KPIs and risks.
- Quarterly portfolio review of priorities, capacity and funding.
- Periodic access, security, supplier and continuity review.
- Annual strategy review or review on material change.

## Segregation of duties

Separate request, approval and reconciliation for high-risk financial/access operations where practical. Where team size prevents separation, use a recorded independent review.

## Reporting

Each active line should report objectives, revenue and costs where relevant, delivery/support workload, customer outcomes, complaints, top risks, incidents and decisions required.
