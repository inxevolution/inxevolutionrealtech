# In X Evolution

> **Project documentation baseline — Draft 0.1 — 23 November 2026**

This repository is dedicated exclusively to the **In X Evolution** project.

## Project status

**Status:** Initiation / discovery.  
**Implementation status:** No application source code or technical stack has yet been established in this repository.

The repository currently provides a controlled starting point for defining the project, recording requirements, making architecture decisions, and governing future implementation. It does not claim that proposed capabilities or architecture are already implemented.

## What is known

- GitHub repository: [inxevolution/inxevolutionrealtech](https://github.com/inxevolution/inxevolutionrealtech)
- Default branch: `main`
- Project name: **In X Evolution**
- The current repository baseline contains a README and a public-domain dedication.

## What is not yet confirmed

The business purpose, target users, products or services, operational processes, regulatory context, technology stack, hosting model, integrations, budget, and delivery dates have not been specified in the repository. These are tracked as open decisions rather than treated as facts.

## Working principles

1. Evidence before assumptions.
2. Requirements before technology selection.
3. Security and privacy by design.
4. Small, reviewable, reversible changes.
5. Automated tests appropriate to each delivery layer.
6. Traceability from requirement to implementation and test.
7. No secrets, credentials, or personal data in source control.

## Scope boundary

Only the **In X Evolution** project is in scope for this repository. Separate projects must not be silently merged into this project. Any future product, business unit, or integration must be explicitly approved and documented as part of the In X Evolution scope.

## Next milestone

Complete project discovery: approve the purpose, users, problem statement, principal outcomes, constraints, and success measures. The technology and detailed implementation plan follow that approval.
